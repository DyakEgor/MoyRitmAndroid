# Мой ритм — нативное Android-приложение

Нативный Android-проект на Kotlin (не веб-приложение и не WebView).

## Получить APK без установки Android Studio

В проект добавлен GitHub Actions workflow `.github/workflows/build-apk.yml`, который собирает APK в облаке.

1. Создайте новый репозиторий на GitHub.
2. Распакуйте архив проекта и загрузите **все файлы и папки** в репозиторий (включая `.github`).
3. Откройте вкладку **Actions** в репозитории и выберите **Build Android APK**.
4. Нажмите **Run workflow** (если сборка не запустилась автоматически после загрузки файлов).
5. Дождитесь зелёной галочки, откройте запуск workflow и внизу раздел **Artifacts**.
6. Скачайте `MoyRitm-debug-apk.zip`, распакуйте его и установите `app-debug.apk` на Android.

GitHub попросит войти в аккаунт. Сборка запускается на серверах GitHub; этот архив сам по себе ещё не содержит APK.

## Сборка локально

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle. Нужны Android SDK Platform 35 и JDK 17 или совместимый JDK.
3. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Функции первой версии
- Главная страница и расписание Б-ПИЭ-23.
- Просмотр дней недели и переключение даты.
- Задачи с отметкой выполнения и приоритетом.
- Привычки: подъём, спортзал, подготовка ко сну.
- Запись тренировок и сна.
- Базовая статистика.
- Локальное хранение через SharedPreferences.

Это debug-сборка для личной установки, а не опубликованная в магазине подписанная версия. Данные хранятся на устройстве; удаление данных приложения может их стереть. Экспорт резервной копии JSON, редактирование регулярных шаблонов, пользовательские привычки и расширенные графики пока требуют доработки.
